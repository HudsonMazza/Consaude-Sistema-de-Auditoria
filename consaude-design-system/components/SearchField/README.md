# SearchField

Campo de busca com ícone, botão de limpar (Esc também limpa) e atalho opcional.

**Você fornece**: `placeholder` que diz o que se busca ("Buscar médico"), `value`/`onChange` ou `defaultValue`, `size`, `pill`, `shortcut`.

- Busque sem diferenciar acentos e maiúsculas; mostre "Exibindo X de Y" e um estado "sem resultados" com "Limpar filtros".

# Badge

Pílula curta de rótulo ou estado, com tons semânticos, contadores, resultado da auditoria e perfil.

**Você fornece**: `tone` (`neutral` | `accent` | `info` | `success` | `warning` | `danger` | `ia` | `outline` | `muted`), `icon`, `size`, `children`. Atalhos: `Count`, `ResultBadge divergences={n}`, `ProfileBadge profile="admin"|"auditor"|"gestor"`.

- Tom sempre com texto; estados sempre com ícone. Não use badge como botão.

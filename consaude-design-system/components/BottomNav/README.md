# BottomNav

Navegação principal do mobile: quatro destinos e a ação central "Nova auditoria".

- Rótulos curtos sempre visíveis (Início, Auditorias, Nova, Usuários, Ajustes); alvos de 64×≥44px; indicador azul no item ativo e badge de pendências.
- Fixa no rodapé com fundo translúcido e `safe-area-inset-bottom`. Não coloque mais de 5 slots.

# Select

Seleção de uma opção num select nativo com o estilo dos campos — acessível e com o seletor do sistema no celular.

**Você fornece**: `options` (`[{ value, label }]`), props nativas, `prefixIcon`, `size`, `pill`. `SelectField` adiciona rótulo, helper e erro.

- Para 2–4 opções visíveis prefira `SegmentedControl`; para listas longas com busca, um combobox.

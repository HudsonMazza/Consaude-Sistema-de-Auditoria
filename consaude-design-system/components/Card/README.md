# Card

Container padrão de blocos: título, subtítulo, ações no cabeçalho e rodapé opcional.

**Você fornece**: `title`, `subtitle`, `icon`, `actions`, `footer`, `flush` (sem padding, para tabelas), `inset` (bloco dentro de card), `glow` (destaque — no máximo um por tela), `headingLevel`.

- Cards não se aninham com borda dupla: dentro de um card use `inset` ou `surface-2`. Nunca use barra colorida lateral.

# Drawer

Painel lateral de 520px para detalhe sem sair da lista (ex.: detalhe do médico); no mobile vira tela cheia com voltar.

**Você fornece**: `open`, `onClose`, `eyebrow`, `title`, `subtitle`, `headerExtra`, `footer` (ações, a primária à direita), `children`.

- Mantenha a linha de origem marcada (`selectedKey` na tabela). Foco preso, Esc fecha e devolve o foco à linha.

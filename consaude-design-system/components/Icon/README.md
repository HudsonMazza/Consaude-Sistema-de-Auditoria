# Icon

Ícones Lucide com traço 1.75 e cor do texto ao redor.

**Você fornece**: `name` (id Lucide, veja `ICON_NAMES`), `size` (padrão 20), `label` quando o ícone carrega sentido sozinho, `strokeWidth`.

- Significados fixos estão no README (IA = sparkles, Excel = file-spreadsheet…). Para adicionar um ícone, copie o SVG do Lucide para `src/icons.js` — não desenhe à mão.

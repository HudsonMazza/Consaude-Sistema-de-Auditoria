# ProgressBar

Barra de progresso linear com rótulo e valor, tons semânticos e modo indeterminado.

**Você fornece**: `value`, `max`, `label`, `valueLabel`, `tone` (`accent` | `success` | `warning` | `danger`), `size="sm"`, `indeterminate`.

- Use para processos (upload, leitura de planilha, geração). Para proporções de um todo prefira `SegmentedMeter`.

# IconButton

Botão só com ícone para ações secundárias compactas (fechar, copiar, mais ações, tema).

**Você fornece**: `icon`, `label` (obrigatório — vira `aria-label` e tooltip), `variant` (`ghost` | `secondary` | `primary`), `size` (`sm` 32 | `md` 40), `round`.

- Use `aria-pressed`/`aria-expanded` para toggles e menus. No mobile a área de toque é ampliada para 44px.

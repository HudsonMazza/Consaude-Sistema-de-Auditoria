# Accordion

Seções expansíveis com resumo do conteúdo no cabeçalho (ex.: "Opções de comparação").

**Você fornece**: `items` (`[{ id, title, subtitle, icon, content }]`), `defaultOpen` (ids), `multiple`.

- O `subtitle` resume os valores atuais para que ninguém precise abrir para saber o que está configurado.

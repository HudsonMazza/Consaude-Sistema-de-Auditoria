# HeroKpi

O número herói da tela no card azul com ondas: o valor que responde "quanto dinheiro está em jogo".

**Você fornece**: `label`, `value` (já formatado), `icon`, `chip` (`HeroChip` com variação ou contagem), `meta` (uma linha de contexto), `actions` (até 2 botões `light`/`deep`), `topAction` (um `IconButton`).

- **Um por tela.** Dashboard: valor divergente do período; Relatório: valor divergente da auditoria. O texto é sempre `on-accent` sobre `accent-fill`.

# DonutChart

Partes de um todo (2–4) com total no centro e legenda com ícone, contagem e valor.

**Você fornece**: `parts` (`[{ label, value, color, icon, sub }]`), `centerLabel`, `size`, `thickness`, `formatValue`.

- Uso principal: Direção dos desvios (laranja `chart-3` × azul `chart-1`). Para mais de 4 partes ou comparação entre períodos use barras.

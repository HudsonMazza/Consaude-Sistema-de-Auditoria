# StatusBadge

Estados com ícone e texto fixos: revisão (Pendente → Revisado → Corrigido), acesso (Ativo, Senha pendente, Desativado), conformidade e processamento.

**Você fornece**: `status` (`pendente` | `revisado` | `corrigido` | `conforme` | `divergente` | `ativo` | `senha-pendente` | `desativado` | `processando` | `erro`), `size`.

- Não invente estados por tela: amplie o mapa `STATUS` do componente para que o ícone e a cor sigam iguais em todo o produto.

# Modal

Diálogo centralizado para tarefas curtas e focadas (novo usuário, confirmar); vira bottom sheet no mobile.

**Você fornece**: `open`, `onClose`, `title`, `description`, `icon`, `tone` (`default` | `danger` | `ia`), `footer`, `size` (`md` | `wide`), `dismissible`, `children`.

- Ação primária à direita no rodapé (empilhada e em largura total no mobile). Evite modais com rolagem longa — use uma página.

# FilterChips

Filtros rápidos em pílula com contagem, de seleção única (radiogroup) ou múltipla (aria-pressed).

**Você fornece**: `options` (`[{ id, label, icon, count }]`), `value`/`onChange` ou `defaultValue`, `multiple`, `scroll` (uma linha com scroll no mobile), `label`.

- Mostre a contagem de cada recorte e "Exibindo X de Y" perto da lista. `SelectChip` representa um seletor que abre menu ou sheet no mobile.

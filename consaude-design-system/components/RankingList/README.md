# RankingList

Top N com posição, nome legível, contexto, valor e barra proporcional (ex.: médicos com maior impacto).

**Você fornece**: `items` (`[{ id, name, meta, value }]`), `formatValue` (padrão `formatBRL`), `onSelect(item)` para tornar a linha clicável.

- Mostre 5; o link "ver ranking completo" vai para a lista filtrada.

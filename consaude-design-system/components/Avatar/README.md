# Avatar

Foto ou iniciais do usuário, com tom derivado do nome, tamanhos de 24 a 56px e estado desativado.

**Você fornece**: `name` (aceita CAIXA ALTA), `src`, `size` (`sm` | `md` | `lg` | `xl`), `off`.

- Decorativo quando o nome está ao lado (`aria-hidden`). Iniciais ignoram partículas ("de", "da").
